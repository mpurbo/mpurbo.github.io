Featured project

HSDD
Hierarchical Spec-Driven Development

The spec is the program.

A methodology and a set of agent skills that scale spec-driven development from a single spec to large, multi-team systems: recursive decomposition, first-class contracts, and one human-reviewed phase at a time.

Read the docs → Interactive guide GitHub
  • 1Decompose the specA tree of nodes joined only by named, versioned contracts, split where ownership splits.
  • 2Phase the leavesEach phase is one coding cycle, sized so a human can review it in one sitting.
  • 3Review every phaseDone means a verification doc a human signed. The human owns correctness; the agent owns throughput.
